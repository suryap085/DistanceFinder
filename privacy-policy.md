## Permissions Justification

### Location Permission (ACCESS_FINE_LOCATION, ACCESS_COARSE_LOCATION)
**Purpose:** Core app functionality for mapping, navigation, and distance calculation  
**Data Use:** Real-time location display, route calculation, nearby place search  
**User Control:** Can be disabled in device settings (with limited functionality)

### Internet Permission (INTERNET, ACCESS_NETWORK_STATE)
**Purpose:** Map data, place search, and directions  
**Data Use:** Downloading map tiles, searching places, calculating routes  
**User Control:** Required for core functionality

### Background Location (ACCESS_BACKGROUND_LOCATION) - if implemented
**Purpose:** Continuous location tracking for navigation  
**Data Use:** Turn-by-turn navigation, location updates during navigation  
**User Control:** Optional permission, can be revoked anytime
